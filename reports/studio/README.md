# گزارش استودیو برای پوش

هر بار که در اپ «قدم بعد» را می‌زنی، این سه فایل بازنویسی می‌شوند:

- `review.md` — گزارش خوانا (دقت، مقایسه با «همیشه بالا»، به‌تفکیک ساعت و منبع)
- `review.csv` — هر تصمیم در یک خط
- `review.json` — همان داده برای پردازش

`var/` در `.gitignore` است، پس گزارش‌ها عمداً اینجا نوشته می‌شوند تا `git status` ببیندشان:

```bash
git add reports/studio && git commit -m "review: $(date -u +%FT%TZ)" && git push
```
